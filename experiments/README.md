\## 主要发现



\- 当前基线分类输入为22个EEG通道，已排除3个EOG通道。

\- 分段时间窗为动作提示出现后0.5–3.5秒。

\- 共288个试次，其中15个带官方伪迹标记：

&#x20; 左手3个、右手3个、双脚4个、舌头5个。

\- 当前基线仍保留这15个试次。

\- 排除EOG通道不等于消除EEG中的眼动干扰。

\- 原基线复现准确率为75.69%，五折标准差为5.57个百分点。



\## 如何运行检查程序



需要Python环境，并安装mne和numpy：



```bash

python -m pip install mne numpy

```



在本文件夹打开终端，将下方数据路径替换为自己的实际路径：



```bash

python inspect\_gdf.py "D:\\你的数据目录\\A01T.gdf" --output inspection\_new.txt

```



结果会显示在终端，并保存到inspection\_new.txt。

脚本不修改原始数据，不筛除试次，不执行分类训练。
